# CopyTeX

将网页上的 KaTeX 和 MathJax 复制为 LaTeX。代码由 AI 生成。

## 安装

[GitHub](https://raw.githubusercontent.com/sgt57/copytex/main/copytex.user.js)

[Greasy Fork](https://greasyfork.org/zh-CN/scripts/595476-copytex)

## 使用

选中文本，按下 Ctrl+C 或右键复制。

当右键菜单未被占用，且 CopyTeX 能够获取源码时，右键单击公式可查看 TeX 源码。

## 兼容性

支持常见的 KaTeX 和 MathJax 版本，以下版本经过测试可以使用：

| 引擎 | 版本 |
|---|---|
| KaTeX | 0.10.2、0.11.1、0.12.0、0.13.24、0.14.0、0.15.6、0.16.0、0.16.11、0.16.22、0.17.0、0.18.7 |
| MathJax 2 | 2.7.0、2.7.5、2.7.9 |
| MathJax 3 | 3.0.0、3.0.5、3.1.4、3.2.0、3.2.2 |
| MathJax 4 | 4.0.0、4.1.3 |

部分网页可能无法使用。
